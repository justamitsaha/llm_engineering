# 4. Why Build a Baseline Model?

A common mistake is to immediately use an LLM.

The recommended approach is:

> **Start simple and build from there.**

Even if you strongly believe an LLM will be the best solution, you should still build a baseline.

### Why?

A baseline gives you:

* A **starting point**
* A benchmark for comparison
* A way to measure whether more sophisticated approaches actually improve performance
* A potentially cheaper and simpler solution

The principle is:

**Start simple → Measure → Improve → Add complexity only when justified**

---

# 5. Traditional ML May Be Enough

Not every business problem requires an LLM.

Some problems may be solved extremely well using:

* Python code
* Traditional machine learning
* Simple mathematical relationships

### Example: Linear Regression

If the true answer is essentially a **weighted combination of features**, linear regression may already provide the appropriate solution.

In that situation, even a sophisticated LLM may not outperform a simple linear model.

### Another example

For something like **credit-card fraud detection**, the relevant patterns may be relatively straightforward.

A traditional ML model could potentially identify those patterns very effectively.

### Key lesson

> **Don't assume the most advanced AI model is automatically the best solution.**

# 6. What Does “Machine Learning” Mean?

The textbook definition is:

> Machine learning is a branch of AI where programs learn from data to make predictions without being explicitly programmed for every prediction.

This is a broad definition that technically includes modern LLMs.

However, in everyday industry terminology, when people say **“machine learning” or “ML”**, they usually mean **traditional machine learning**.

---

# 7. Traditional ML vs Modern LLMs

Traditional ML generally refers to models that predate the recent deep-learning/LLM era.

Examples include:

* **Linear Regression**
* **Random Forest**
* **XGBoost**
* **Support Vector Machines (SVMs)**

LLMs are technically machine-learning models, but people generally don't use “ML” to mean LLMs in everyday industry discussions.

### Important point

Traditional ML is still relevant because:

1. Some business problems are better suited to traditional ML.
2. Traditional ML teaches foundational concepts needed to understand modern AI.

# 9. Generalization

One of the most important concepts in machine learning is **generalization**.

### Definition

**Generalization = the ability of a model to perform well on unseen data.**

Suppose we have:

* 10,000 credit-card transactions
* 5,000 fraudulent
* 5,000 legitimate

We can extract features such as:

* Transaction amount
* Other transaction characteristics
* Patterns associated with fraud

The model learns patterns from these examples.

Generalization occurs when the model can then receive a **new transaction it has never seen before** and correctly predict whether it is likely to be fraudulent.

### The goal

The model shouldn't simply memorize the training examples.

It should learn **patterns that apply to new data**.

---

# 10. Overfitting

**Overfitting** occurs when a model becomes too closely fitted to its training data.

This can happen when the training data contains:

* Noise
* Anomalies
* Accidental patterns

The model may learn these things as though they were genuine real-world patterns.

### Result

The model can perform extremely well on the training data but perform poorly on new data.

Conceptually:

**Training data → Model learns real patterns + noise → Poor performance on unseen data**

---

# 11. Relationship Between Generalization and Overfitting

The goal is:

**Learn useful patterns → Generalize → Perform well on unseen data**

Overfitting works against this goal:

**Learn training data too specifically → Memorize noise → Poor generalization**

The transcript also notes that overfitting can occur when training is continued too much on the same data.

---

# 12. Generalization Applies to LLMs Too

The same principle applies to modern LLMs.

An LLM receives:

**Input: sequence of tokens**

and produces:

**Output: probability distribution for the next token**

The model is trained using enormous amounts of data.

### Generalization in an LLM

Suppose an LLM encounters a conversation in ChatGPT that wasn't explicitly present in its training data.

If it can still produce a sensible response based on patterns it learned during training, that is **generalization**.

So:

**Traditional ML → Generalization**

and

**LLMs → Generalization**

The underlying concept is the same.

# Key Takeaways

* **Always build a baseline before jumping to sophisticated AI.**
* Start with the **simplest reasonable solution** and add complexity only when justified.
* Traditional ML can outperform or be more appropriate than LLMs for certain business problems.
* Common traditional ML models include **Linear Regression, Random Forest, XGBoost, and SVMs**.
* “Machine learning” in everyday industry language usually refers to **traditional ML**, even though LLMs are technically machine-learning models.
* Traditional ML provides important foundations for understanding modern LLMs.
* **Generalization** means performing well on unseen data.
* **Overfitting** means learning the training data too specifically, including noise or accidental patterns, resulting in poor performance on unseen data.
* The ultimate goal of ML is **generalization**, not memorization.
* Generalization is a fundamental concept in both traditional ML and LLMs.
* For the Price Is Right project, traditional ML will provide a **baseline** before moving to neural networks, frontier LLMs, and fine-tuning.
* The central workflow is:

**Start Simple → Build Baseline → Evaluate → Compare → Add Complexity**
